💡 สรุปประเด็นเชิงลึก (Key Consumer Insights)

  • กำลังประมวลผลข้อมูล...

1. ความต้องการฟีเจอร์ในแอป (ส่วนที่ 3 ข้อ 1)

ฟีเจอร์ที่ผู้ใช้ต้องการมากที่สุด

2. ประเภทเอกสารที่ยุ่งยากที่สุด (ส่วนที่ 2 ข้อ 1)

เอกสารที่พบปัญหาตอนสมัครงานหรือเริ่มต้นทำงาน

3. ช่องทางรับรู้สื่อและเครื่องมือใหม่ๆ (ส่วนที่ 5)

ช่องทางที่คนรุ่นใหม่ค้นหาหรือรับข้อมูล

4. รูปแบบค่าบริการที่ยินดีจ่าย (ส่วนที่ 6 ข้อ 2)

ฟรีดูโฆษณา / รายเดือน / รายปี / ซื้อขาด

ตารางข้อมูลคำตอบจริง (Raw Responses)

สามารถกดปุ่ม "ลบ" ในแต่ละแถวเพื่อลบคำตอบทดสอบออกได้ทันที

จัดการ เวลา อายุ สถานภาพ ที่พักอาศัย ฟีเจอร์ที่ต้องการ เหตุผลเปิดใช้ครั้งแรก แนวโน้มใช้ประจำ มิติชีวิต โมเดลราคา การรับรู้ ข้อเสนอแนะ
ยังไม่มีข้อมูลคำตอบจริงในระบบ (สามารถทดลองทำแบบสอบถามเพื่อดูผลได้ทันที)

⚙️ ตั้งค่า Google Sheets Webhook URL

นำ Web App URL ที่ได้จากการ Deploy สคริปต์ใน google-apps-script.js มาวางที่นี่ (ต้องลงท้ายด้วย /exec ไม่ใช่ /dev)

ใช้สำหรับให้หน้า Admin อ่านข้อมูลรวมจาก Google Sheets กลาง ไม่ต้องใส่ในหน้าแบบสอบถาม
